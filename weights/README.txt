Models in this release

The public release includes:

    maia3-5m.bin

The 5M model is the recommended phone model and is bundled with the public
release.

Optional larger models can be added manually:

    maia3-23m.bin
    maia3-79m.bin

The app can load additional .bin files from device storage and cache them.

For the bundled 5M model's provenance and upstream licensing information, see:

    weights/NOTICE-maia3-5m.txt
